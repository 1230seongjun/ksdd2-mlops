# 검사 웹 UI

`zerodefect-ui.html`은 HTML, CSS, JavaScript(`assets/zerodefect-ui/`)로 검사·인증·이력 화면을 제공합니다. 브라우저는 Nginx의 `/api/`를 통해 FastAPI에 요청합니다. [API](../api/README.md)와 [서비스](../../infra/service/README.md)를 참고합니다.

## 이미지 검사

PNG/JPEG 이미지의 입력 규격은 가로 184 × 세로 597px, 최대 5 MiB입니다. 탐지 및 분류 모델 버전을 선택해 검사하고 판정, 결함 종류, 영역, JSON을 확인합니다. 목록 선택, 이미지 추가·삭제, 검사 중단·재개·재검사, 진행 따라가기와 JSON 저장을 제공합니다.

## 검사 이력

관리자는 전체, 일반 작업자는 본인 이력을 조회합니다. 날짜·파일명·판정을 검색하고 50건 단위로 페이지를 이동합니다. 파일명, 작업자 식별, 탐지·분류 모델 버전, 판정, 종류, 검사 시각과 상세를 확인합니다. 상세에는 요청 ID, 모델 URI, 점수, 신뢰도, 영역과 처리 시간이 포함됩니다. 원본 이미지 자체는 이력 DB에 보관되지 않습니다.

## 배포와 확인

API의 이력 응답과 화면 버전이 호환돼야 합니다. 검사 결과 저장은 응답 후 백그라운드로 진행되므로, 저장 여부는 DB 기록으로 따로 확인합니다.
