# 불량제로 검사 웹 UI

브라우저는 Nginx의 `/api/`를 통해 FastAPI를 호출합니다. Nginx가 제공하는 시작 파일은 [zerodefect-ui.html](zerodefect-ui.html)입니다. [API 계약](../api/README.md)과 [서비스 실행·인증](../../infra/service/README.md)을 함께 참고합니다.

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| [zerodefect-ui.html](zerodefect-ui.html) | 로그인·검사·이력·모니터링·재학습 화면과 대화상자 |
| [console.css](assets/zerodefect-ui/console.css) | 화면·패널·박스 표시 스타일 |
| [inspection.js](assets/zerodefect-ui/inspection.js) | 파일 추가·검사·모델 준비·결과·재검토·JSON 저장 |
| [session.js](assets/zerodefect-ui/session.js) | 로그인·가입·초대·역할·탭·이력·재학습 요청 |
| [text-size.js](assets/zerodefect-ui/text-size.js) | 글자 크기 조절 |

## 이미지 검사

PNG/JPEG, 가로 184×세로 597px, 최대 5 MiB를 받습니다. 다중·폴더 업로드, 탐지·분류 버전 독립 선택, 조합 준비 후 순차 검사, 진행률·따라가기·중단·재개·선택 재검사, 유형·박스·JSON 표시와 저장을 제공합니다. 중단은 현재 요청의 서버 실행 취소가 아니라 다음 이미지부터 멈추는 동작입니다.

크기 오류는 재검토 화면에서 규격에 맞는 파일로 교체하거나 제외할 수 있습니다. 자동 리사이즈하지 않으며 API 직접 요청도 규격을 다시 검사합니다.

## 재검토·최종 판단

불량 판정에서 박스가 없거나 유효한 유형이 없으면 API가 `review_required`를 반환합니다. 신뢰도 0.88은 현재 API 재검토 기준이 아닙니다.

- 정상 확정: 작업자 최종 판단 저장 후 정상으로 표시합니다.
- 불량 확정: 결함 유형을 선택하고 필요하면 박스를 그리거나 수정·삭제해 저장합니다. 유형은 필수, 박스는 선택입니다.
- 취소: API에 취소를 저장한 뒤 화면에서 제외합니다. 크기 오류 제외는 추론 요청이 없는 별도 UI 처리입니다.
- 재검사: 새 요청 ID로 검사해 성공하면 화면 결과를 교체합니다. 실패 시 기존 결과와 재검사 실패 메시지를 유지합니다.

재검토는 대기 메타데이터 저장 후 응답하고, 확정 시 모델 원본과 `reviewed_*` 판단 컬럼을 분리해 최종 이력에 저장합니다. 일반 결과는 DB 활성화 시 응답 후 저장합니다. 대기 저장 실패는 503이며, UI에서 결과를 받았다는 것만으로 최종 이력 저장 완료를 판단하지 않습니다. 원본 이미지 자체는 이력 DB에 보관하지 않습니다.

재검사 후 이전 대기 기록 정리 호출은 확인되지 않았으며 실제 DB 대조가 필요한 후속 항목입니다. 화면에서 이미지 삭제·새로고침하는 것과 서버 대기 건의 취소·정리는 같은 작업으로 간주하지 않습니다.

## 이력과 역할별 화면

관리자는 전체, 작업자는 본인 이력을 조회하는 API를 사용합니다. 날짜·파일명·판정·검토 여부·점수 등으로 필터링하고 50건 단위로 페이지를 이동합니다. 관리자는 조회 계정도 선택할 수 있습니다. 상세에는 요청 ID·모델 URI·점수·신뢰도·영역·시간과 검토 결과 등이 포함됩니다.

UI는 관리자에게 작업자·관리자 모니터링 선택을 제공하고 작업자에게 관리자 화면을 열지 않습니다. iframe은 작업자 `worker-dashboard`, 관리자 `admin-dashboard`를 사용합니다. 서버 세션 인증과 Grafana 내부 권한도 함께 적용하며, 비로그인 차단·역할별 접근은 사용자 검증으로 확인했습니다. 작업자별 데이터 행 격리와 패널 통계 정합성은 별도 검증 범위입니다.

## 배포·검증·후속 개선

`serving/web/` 전체가 `/opt/bulryangzero/service/web/`로 동기화됩니다. HTML과 assets를 함께 반영해야 합니다. API 변경은 별도 이미지 배포이므로 이력 응답의 `total_pages` 등과 웹 버전 호환을 확인합니다. 로그인 직후 hidden 오류가 나면 탭·패널 ID와 초기화 순서를 확인합니다.

정상·불량·크기 오류, 검사 중단·재개, 재검토 확정·취소, 필터·페이지와 DB를 요청 ID로 대조하는 것이 기능 검증입니다. 이번 문서 정리에서 이를 모두 다시 실행하지 않았습니다.

운영 작업자 패널 SQL·변수와 iframe URL에는 폐기한 `low_conf=0.88`이 남아 있습니다. 별도 패널 담당자와 집계 의미를 합의한 뒤 SQL·변수·색상·URL·관련 알림을 함께 정리할 후속 항목입니다. 현재 패널의 확인 필요 수치를 API 재검토 대기 건수와 동일하다고 보장하지 않습니다. LOT·작업자 간 검사 공유는 별도 검토 사항입니다.
